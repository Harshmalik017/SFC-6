# DESIGN
Current direction: cleaner executive dashboard, more action-oriented navigation, and richer semantic color coding by factsheet level.

- Header: dark gradient slate-to-slate with white text and layered hover states.
- Page surface: light gradient backgrounds, soft white cards, subtle shadows, rounded panels.
- Factsheet themes: State = sky/cyan, District = violet/indigo, Block = amber/orange, Gram Panchayat = emerald/green, Urban Local Body = fuchsia/pink.
- KPI tiles: card-based summaries with color-coded accent dots and theme-tinted gradients.
- Charts: interactive Recharts panels for receipts trend, funding mix, and tier-wise contribution.
- Navigation: quick-explorer selector with mode labels and stronger hierarchy for rural/urban drill-down.
- Tables and category filters: compact, horizontally scrollable tables; filter chips and section icons inherit each factsheet's palette, with clear source/download actions.
- Icons: lucide (Landmark state, MapPinned district, LayoutGrid block, TreePine GP, Building2 urban, FileText/FileSpreadsheet/FileJson downloads).
- Responsive: hamburger nav, 1→2→4 column grids, and card-first layout for dashboard reads.
- Favicon: app/icon.svg.
